# 设计契约：青瓷数字诗馆

## 目标模式

兰泽不是仪表盘，也不是通用内容社区。它被定义为一间可以本地打开的「数字诗馆」：每次进入，先安静地读完一首诗；需要更多时，再进入索引、诗卷或写作台。界面不模拟运营数据、在线用户或商业服务。

一句话目标：**让一首诗、一张图、一张历史摘录卡与一组索引线成为页面的全部主角。**

## 设计原则

1. 一首诗一展厅：首屏只呈现当天的一首诗与一张视觉注释；读完后的余韵区只保留一张历史摘录卡，不放通用卡片矩阵或轮播。
2. 内容先于装饰：编号、细线与边框用来标识卷次、体裁和展品边界，不作为通用装饰。
3. 冷瓷与铜金：冷白瓷面、青灰线框、少量铜金作为索引色，不使用暖纸、朱印、渐变卡片或 SaaS 阴影。
4. 一首诗的字体尺度：诗题按长度分级；含词牌的长题拆为两行，避免撑破展台或移动端视口。
5. 克制的动效：换诗时只改变正文透明度，路由切换只淡入淡出；其余动画只响应用户操作，并遵循 `prefers-reduced-motion`。
6. 稳定优先：诗句展台保留最小高度，路由过渡不移动内容，图片声明尺寸，避免字体或图片加载引起布局抖动。
7. 摘录有边界：余韵区按历史提交 `45b1308` 的白色摘录卡等比还原，保留旋转收藏角标、竖排诗句与作者、水墨扇舟图和悬浮高光；只显示一张，不恢复完整三卡行或旧 UI 套件。诗句可来自默认公开随机源、部署者自建兼容接口或内置摘录，页面不隐藏实际来源。
8. 真实状态：空收藏、未登录、搜索无结果都给出明确下一步；诗句源加载、失败回退和重复诗句都给出可读状态，摘录收藏按诗句内容只保存在当前浏览器，不描述成诗卷内的完整诗目或跨设备同步。
9. 响应式优先：桌面为双栏展台，窄屏自动改为单列；页头吸附顶部，本地播放器吸附视口并可收起，移动端底部导航与通知层避开播放器。
10. 技术自洽：界面只使用仓库自有组件、CSS token 与浏览器原生能力；不依赖 Element Plus、Bootstrap、Font Awesome、Lottie、APlayer 或滑块验证码。

## 视觉 token

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 瓷面 | `#f3f5f0` | 页面主背景 |
| 深瓷 | `#e8ece5` | 索引区、页脚与分层背景 |
| 瓷板 | `#fbfcf9` | 表单、诗笺与展品内框 |
| 青瓷 | `#a8c4b8` | 辅助色、成功态与细线 |
| 深青 | `#517a70` | 交互焦点与计数 |
| 墨 | `#162c2b` | 正文与主要按钮 |
| 铜金 | `#a88245` | 编号、分类、标题细节与焦点 |
| 夜青 | `#102827` | 登录左栏、音源与通知控件 |

字体分为两类：诗题与诗句使用 `LanZeSong` / 系统宋体；界面文字使用 `PingFang SC` / `Avenir Next` 一类无衬线字体。运行时只加载按仓库可见字符生成的 WOFF2 子集，并声明字体度量覆盖，避免 14 MB 历史字体进入构建产物或造成字体替换时的行高跳动。

## 页面契约

| 页面 | 主任务 | 主操作 | 必须出现的空/错误状态 |
| --- | --- | --- | --- |
| 今日展厅 `/` | 读完当天一首诗，再看一张历史摘录卡 | 收入诗卷、朗读、展开笺注、换一首、收藏摘录、换一句摘录 | 数据载入中的可读文本 |
| 寻诗 `/explore` | 搜索并筛选诗目 | 检索、体裁筛选、清除条件、收藏 | 无结果时提供查看全部入口 |
| 读诗 `/poem/:id` | 阅读正文、标签与笺注 | 收藏、朗读、复制链接、返回索引 | 找不到诗时解释本地数据边界 |
| 我的诗卷 `/collection` | 查看收藏、最近阅读与本地作品 | 切换分类、移除、编辑资料、退出登录 | 各分类的空状态与登录引导 |
| 写作台 `/compose` | 起草并发布本地作品 | 自动保存草稿、预览、发布、清空 | 未登录时跳转登录、必填校验、发布失败提示 |
| 登录 / 注册 | 建立本地演示会话 | 登录、注册、填入演示账号 | 字段校验、账号冲突、密码错误提示 |

## 拒绝模式

- 首页不使用三折经卷、轮播图、彩色头像墙、统计仪表盘或「热门」卡片；余韵区的一张白色历史摘录卡是用户明确要求保留的样式例外。
- 不为显得内容丰富而显示空的社区栏目；旧路由统一重定向到新的三段式信息架构。
- 不为了视觉统一给所有元素套同一个圆角、阴影或渐变。
- 不重新引入旧 UI 套件；`npm run lint` 会阻止这些依赖回到视图层。
- 不把本地 `localStorage` 演示描述成线上账号、跨设备同步或正式内容服务。

## 验收清单

- [ ] 桌面 1440px：首屏诗题不与插图重叠，长题按词牌/题名分行。
- [ ] 余韵区始终呈现一张历史白色摘录卡；收藏和「换一句」可键盘操作，竖排文本与扇舟图不溢出。
- [ ] 窄屏 390px：诗题、正文、按钮与编号不横向溢出。
- [ ] 键盘焦点可见；表单有可见标签或 `aria-label`。
- [ ] 收藏、搜索、登录、发布、朗读与本地音源回退均可操作。
- [ ] `npm run lint`、`npm run test`、`npm run build`、`npm run smoke`、`npm run smoke:browser` 通过，浏览器冒烟 CLS 预算不超过 0.05。
- [ ] 浏览器控制台无错误；不请求第三方字体、图标、动画或音乐服务。首页诗句源是唯一可选第三方运行时请求，浏览器冒烟会拦截它并验证来源状态；其它网络请求不得失败。
- [ ] 构建产物只加载 WOFF2 字体子集与压缩展品图；桌面/窄屏切换时不出现页面级横向滚动或 CLS 跳动。
- [ ] 页头为 `sticky`，播放器/移动导航/通知层为 `fixed`；滚动时播放器仍完整位于视口内且可展开/收起。
