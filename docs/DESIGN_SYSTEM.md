# 设计契约：青瓷数字诗馆

## 目标模式

兰泽不是仪表盘，也不是通用内容社区。它被定义为一间可以本地打开的「数字诗馆」：每次进入，先安静地读完一首诗；需要更多时，再进入索引、诗卷或写作台。界面不模拟运营数据、在线用户或商业服务。

一句话目标：**让一首诗、一张图、一张历史摘录卡与一组索引线成为页面的全部主角。**

## 设计原则

1. 一首诗一展厅：首屏只呈现当天的一首诗与一张视觉注释；读完后的余韵区只保留一张历史摘录卡，不放通用卡片矩阵或轮播。
2. 内容先于装饰：编号、细线与边框用来标识卷次、体裁和展品边界，不作为通用装饰。
3. 冷瓷与铜金：冷白瓷面、青灰线框、少量铜金作为索引色，不使用暖纸、朱印、渐变卡片或 SaaS 阴影。
4. 一首诗的字体尺度：诗题按长度分级；含词牌的长题拆为两行，避免撑破展台或移动端视口。
5. 克制的动效：首屏只做一次编排入场；换诗、收藏、切轨、筛选、草稿保存与发布用短促的状态反馈解释变化；路由切换只淡入淡出；其余非用户触发动画不出现，并遵循 `prefers-reduced-motion`。
6. 稳定优先：路由舞台在异步页面解析前预留一屏高度，页脚不会先出现在首屏再被推走；诗句展台保留最小高度，路由过渡不移动内容，图片声明尺寸，避免字体或图片加载引起布局抖动。
7. 摘录有边界：余韵区按历史提交 `45b1308` 的白色摘录卡等比还原，保留旋转收藏角标、竖排诗句与作者、水墨扇舟图和悬浮高光；只显示一张，不恢复完整三卡行或旧 UI 套件。卡片不响应拖拽，也没有纸幕、飞出、粒子、整卡翻转或切换位移；点击卡片或外部「换一句」按钮触发「换墨」过渡：诗句与作者 120ms 淡出上移，静默换句后 260ms 淡入落位，只动文字层，卡面、收藏角标、扇舟图与 hover 光泽不参与切换。收藏按钮仍是独立控件，点击不会触发换句。保留历史白卡的 hover 光泽与轻微悬浮过渡；`prefers-reduced-motion` 关闭过渡但保留点击切换。长句使用更克制的字号与字距、诗句与画面保留更宽的左右内边距、画面边缘轻融纸面、收藏态使用低饱和朱砂与可见焦点。诗句默认来自仓库内置摘录与精校馆藏短句，显式开启远程源后才使用部署者自建兼容接口或公开随机源，页面不隐藏实际来源。
8. 真实状态：空收藏、未登录、搜索无结果都给出明确下一步；诗句源默认取自仓库内摘录与精校短句，显式开启远程源时的加载、失败回退和重复诗句都给出可读状态，摘录收藏按诗句内容只保存在当前浏览器，不描述成诗卷内的完整诗目或跨设备同步。
9. 响应式优先：桌面为双栏展台，窄屏自动改为单列；页头吸附顶部，本地声景播放器吸附视口并可收起。所有宽度冷启动都是一枚不遮正文的「声景签」：默认收起、静音且不自动播放；点击展开后变为对齐主题、结构稳定的「声景卷」，再次点击才收起。窄屏与底部导航分层，通知层避开两者。320px 是布局底线，解释性文案与次级图标为该宽度让位，主操作仍保留可读触控尺寸。
10. 技术自洽：界面只使用仓库自有组件、CSS token 与浏览器原生能力；不依赖 Element Plus、Bootstrap、Font Awesome、Lottie、APlayer 或滑块验证码。
11. 文字可读：界面辅助文字通常不小于 11px；中文标题与标签不堆叠过大字距，段落控制在舒适行长并使用 `pretty`/`balance` 换行，诗题最多两行完整呈现而不是 ellipsis 截断。历史白色摘录卡的竖排诗句仍按原构图例外处理。
12. 固定层留白：窄屏主内容由 `--fixed-layer-space` 为音频层与底部导航预留安全区；播放器只由 handle 显式切换两态，悬停、聚焦、路由变化、展开或断点变化都不会替用户播放声景，展开高度保持通知层避让预算。
13. 状态完整性：同一断点的固定层、页脚与主内容共用安全区；隐藏装饰区不进入 Tab 顺序，暗色固定层的焦点可见，展开态控件与操作中的按钮都有明确反馈。语义按元素实际行为使用导航、标签页或普通链接，不为视觉统一套用同一套 ARIA。
14. 登录诗笺：桌面登录左栏的两行《越人歌》按真实竖排诗笺排列，两行顺序符合原诗、各自完整成列、出处竖排贴边且不散字；窄屏隐藏装饰区后不留下空框或错位文字。

## 视觉 token

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 瓷面 | `#f3f5f0` | 页面主背景 |
| 深瓷 | `#e8ece5` | 索引区、页脚与分层背景 |
| 瓷板 | `#fbfcf9` | 表单、诗笺与展品内框 |
| 青瓷 | `#a8c4b8` | 辅助色、成功态与细线 |
| 深青 | `#517a70` | 交互焦点与计数 |
| 墨 | `#162c2b` | 正文与主要按钮 |
| 铜金 | `#a88245` | 编号、分类、标题细节与焦点 |
| 夜青 | `#102827` | 登录左栏、音源与通知控件 |

字体分为两类：诗题与诗句使用 `LanZeSong` / 系统宋体；界面文字使用 `PingFang SC` / `Avenir Next` 一类无衬线字体。运行时只加载按仓库可见字符生成的 WOFF2 子集，并声明字体度量覆盖，避免 14 MB 历史字体进入构建产物或造成字体替换时的行高跳动。

## 页面契约

| 页面 | 主任务 | 主操作 | 必须出现的空/错误状态 |
| --- | --- | --- | --- |
| 今日展厅 `/` | 读完当天一首诗，再看一张历史摘录卡 | 收入诗卷、朗读、展开笺注、换一首、收藏摘录、换一句摘录 | 数据载入中的可读文本 |
| 寻诗 `/explore` | 搜索并筛选诗目 | 检索、体裁筛选、清除条件、收藏 | 无结果时提供查看全部入口 |
| 读诗 `/poem/:id` | 阅读正文、标签、笺注并继续读下一首 | 收藏、朗读、复制链接、上一首/下一首、返回索引 | 找不到诗时解释本地数据边界 |
| 我的诗卷 `/collection` | 查看收藏、最近阅读与本地作品 | 切换分类、移除、编辑资料、退出登录、回读作品 | 各分类的空状态与登录引导 |
| 写作台 `/compose` | 起草并发布本地作品 | 自动保存草稿并反馈时间、同步预览、发布、清空 | 访客可预览并保留草稿，发布时引导登录；必填校验、发布失败提示 |
| 登录 / 注册 | 建立本地演示会话 | 登录、注册、填入演示账号 | 字段校验、账号冲突、密码错误提示 |

## 拒绝模式

- 首页不使用三折经卷、轮播图、彩色头像墙、统计仪表盘或「热门」卡片；余韵区的一张白色历史摘录卡是用户明确要求保留的样式例外。
- 不为显得内容丰富而显示空的社区栏目；旧路由统一重定向到新的三段式信息架构。
- 不为了视觉统一给所有元素套同一个圆角、阴影或渐变。
- 不重新引入旧 UI 套件；`npm run lint` 会阻止这些依赖回到视图层。
- 不把本地 `localStorage` 演示描述成线上账号、跨设备同步或正式内容服务。

## 验收清单

- [ ] 桌面 1440px：首屏诗题不与插图重叠，长题按词牌/题名分行。
- [ ] 余韵区始终呈现一张历史白色摘录卡；收藏和「换一句」可键盘操作，卡片跟手拖动、越过较小阈值提前翻走、底层新卡落纸显墨，鼠标与触屏行为一致，竖排文本与扇舟图不溢出。
- [ ] 窄屏 390px 与 320px：诗题、正文、按钮与编号不横向溢出；检索行、筛选面板、写作表单和底部固定层不互相遮挡。
- [ ] 键盘焦点可见；表单有可见标签或 `aria-label`。
- [ ] `aria-hidden` 装饰区没有可 Tab 聚焦的链接/按钮/输入框；登录切换为普通导航，诗卷标签与面板有可解析的关联；按钮禁用、等待与展开状态有可见反馈。
- [ ] 辅助文字不小于 11px，诗题不再单行省略，说明段落行长与换行可读；播放器冷启动收起且静音，显式展开后保持完整控件，收起后回到安静的声景签。
- [ ] 收藏、换诗、诗路筛选、连续阅读、搜索、登录、发布、朗读、本地声景曲库切换/进度/音量与自定义音源回退均可操作。
- [ ] `npm run lint`、`npm run test`、`npm run build`、`npm run smoke`、`npm run smoke:browser` 通过，冷启动与全流程 CLS 预算均不超过 0.05。
- [ ] 浏览器控制台无错误；不请求第三方字体、图标、动画或音乐服务。首页诗句源是唯一可选第三方运行时请求，浏览器冒烟会拦截它并验证来源状态；其它网络请求不得失败。
- [ ] 构建产物只加载 WOFF2 字体子集与压缩展品图；桌面/窄屏切换时不出现页面级横向滚动或 CLS 跳动。
- [ ] 页头为 `sticky`，播放器/移动导航/通知层为 `fixed`；桌面与窄屏播放器都默认收起、不自动播放且不与诗句展台或主要操作相交；窄屏主内容保留固定层安全区，滚动时仍完整位于视口内且可显式展开/收起；收起签与展开卷两态对齐同一主题，播放列表、进度与音量控件不造成横向溢出。
- [ ] 641–820px 也使用窄屏固定层断点；通知层在播放器展开时仍不相交，页脚底部留白不少于 `--fixed-layer-space`，展开播放器与通知关闭按钮保持一致的触控高度。
- [ ] 桌面登录左栏诗句保持两列竖排、字词不横向拆散；`prefers-reduced-motion` 下摘录卡跳过掀卡与显墨动画但仍可换句。
